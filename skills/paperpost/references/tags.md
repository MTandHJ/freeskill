## Selection Rules

- Keep `Paper` first.
- Use one to three topic tags before type / venue / year.
- Set venue and year from the paper facts; they do not need to come from this file.
- Prefer existing spellings exactly, including capitalization.
- Use `Empirical` for experiment-driven papers.
- Use `Theoretical` or `Theory` only when the paper is mainly theoretical; preserve the existing tag if already obvious from context.
- Add `Seminal` for foundation papers that are historically central, not merely highly cited.
